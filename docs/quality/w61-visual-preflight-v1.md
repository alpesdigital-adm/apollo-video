## Frozen corpus protocol

Primary source: Open Images V7 official download and data-format pages. Use the exact official URLs in that page for V7 validation/test *boxes*, human-verified image-level labels, boxable class names, and image metadata; record URL and SHA-256 of each CSV. `Human face` MID is `/m/0dzct`. Accept positive face boxes only where `Source=xclick` or `activemil` (human drawn/verified). Use `Confidence=0`, `Source=verification` or `crowdsource-verification` image labels for face-negative samples; an absent positive box alone is never a negative label. Exclude `IsGroupOf=1`, depictions, and boxes with invalid geometry. A person box is not a face box.

Use official **validation** for two disjoint sets: development if the first byte of SHA-256(`w61-v1|validation|<image-id>`) is 0–127, calibration otherwise. Use official **test** as sealed holdout. This partition is fixed before any image selection or inference; no ID crosses its boundary. Fixed sampler version `w61-v1`: for each set, normalize image IDs to lowercase; filter the exact image metadata to a per-image CC BY 2.0 or CC BY 4.0 license URL and a retrievable original; order eligible IDs by SHA-256 of UTF-8 `w61-v1|<set>|<stratum>|<image-id>` ascending, then ID ascending. Select the first 10 images in each *mutually exclusive* positive stratum in this order: (1) at least two eligible faces; (2) one face with center Y >= 0.65; (3) one face occupying <= 2% of image area; (4) remaining one face. Select the first 20 verified face-negative images as a fifth stratum. Maximum 60 images per set. The first applicable stratum wins. Exclude duplicate image IDs across strata/splits. Never replace a selected ID because its pixels, licensing, download, prediction, or labels are inconvenient; record the failure and reduce N. Freeze selected IDs, annotation rows, image URLs/licenses/authors, pixel hashes, and selection script hash in a manifest **before inference**. Keep the holdout sealed until all model settings and thresholds are fixed using development/calibration only. No model outputs may change the sample.

Image licenses are checked per image from the official metadata **and the original landing page where reachable**. If the original page does not confirm the compatible license, quarantine the image and count it as unavailable; do not replace it. Preserve author, attribution URL, original landing URL, license, and hash. Keep images outside the repository; do not redistribute them. Open Images annotations are CC BY 4.0, but that does not override each image's own license. These still images cannot establish blur, skin tone, eye visibility, video motion, temporal tracking, or all real Apollo layouts; those strata need independently adjudicated frames before W62/W67 acceptance. No machine-generated annotation is human ground truth. The model README credits WIDER FACE as training data; Open Images is independent by source, but absence of individual-image overlap with training is not proven.

## Frozen measurements and pass/fail boundaries

- Decode and rotate pixels per official metadata. Run CPU only, 640 px longest side with aspect ratio retained, no upscaling; confidence cutoff **0.50**, NMS **0.30**, top K **5000**, no test-set tuning. Preserve original-image boxes after inverse mapping. A ground-truth face matches a detection at IoU >= **0.50** with one-to-one greedy matching by descending IoU. Separately report IoU >= 0.30 for small-face diagnosis, never substitute it for the primary metric.
- For each set and each nonempty stratum report image and face counts, matched/missed faces, false detections, recall, precision, median/P95 IoU, and confidence reliability bins (0.5–0.6, 0.6–0.7, 0.7–0.8, 0.8–0.9, 0.9–1.0). Report Wilson 95% lower bound for recall. A negative image with any detection is a false-positive image. All downloads/decodes excluded from inference metrics are reported and count against sample completeness. IoU quantiles among matches already constrained to >= 0.50 are descriptive, not a separate gate.
- Candidate may proceed to W62 integration work only if the pinned weight and license checks pass; >= 90% of selected images per set are decoded; holdout has >= 30 eligible faces and >= 10 negatives; overall holdout face recall >= **0.95**, each face stratum recall >= **0.90** where it contains >= 10 faces, and face-negative image false-positive rate <= **0.10**. Missing mandatory strata keep the corpus gate open even if aggregate metrics pass. A confidence bound with this tiny sample is diagnostic, not proof of a population safety guarantee. Failure remains `review/block`.
- CPU spike: Windows local process, one inference worker, no GPU; <= **512 MiB** additional peak RSS, median <= **150 ms** and P95 <= **500 ms** per 640 px frame over 30 warm runs after 3 warmups; CPU <= 2 execution threads; 30-second maximum test run, no unbounded batch. Store runtime/Python/CPU details and peak RSS. Any timeout, crash, NaN, malformed box, missing weight, or hash mismatch fails closed.
- This candidate preflight does **not** authorize automatic subtitle/crop approval. Product readiness additionally requires independent video and face/eye ground truth, temporal coverage, variant-specific MP4 inspection, API/PG/worker contracts, and independent final-pixel critic. No score from this corpus alone closes those gates.
