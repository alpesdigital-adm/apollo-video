# ADR-140 — Release risks, v1 reuse and public defaults

Eleven risks were named for executable control: phase scope, subjective quality, cost, providers, claim context, synchronization, library governance, UI boundaries, prompt injection, storage growth and automation abuse. **They are not controlled by executable gates today.** The single module that implemented them, `src/v2/application/release-risk-control.ts`, was deleted on 2026-09-04 by commit e8ba18e6. Every gate in it was a one-line pure function over scalars the caller passed in — `canReleasePhase(phase, approved: Set<string>)` answered from the set of phases the caller declared approved, `costRiskGate` from the `preflight`/`cacheChecked`/`deduped` booleans the caller asserted — and none of the eleven had a runtime call site. A gate that reads its verdict off its own argument is the AGENTS.md anti-pattern, so removing it removed no control; it removed the appearance of one.

What survives is two gates that read server evidence instead of caller claims: `src/v2/domain/mvp-core-gate.ts` and `src/v2/domain/multicam-longform-gate.ts`, the second reading ten criteria and thirty-eight checks off persisted rows through `src/v2/infrastructure/prisma/multicam-longform-gate-repository.ts`, with every reference carrying the table and hash it was read from. Between them they cover phase scope and synchronization. Rebuilding the other nine on that same server-evidence pattern is open work with no owner and no date; until then this ADR claims a policy, not a control.

V1 code is never reused by proximity. Characterization plus a v2 contract, zero direct v1 imports and favorable extraction cost are mandatory.

Public defaults for F1/F2/F3/F5 remain in force as decisions and are recorded in prose in `docs/PUBLIC-RELEASE-DECISIONS.md`. They are no longer fixed by a test. `RELEASE_DECISIONS` and `validateReleaseDecisionRecord` went with the same module, so the test id `T-DECISION-001` — still cited as evidence by twenty-one lines of TODO.md until 2026-09-07 — names nothing that runs. A default recorded only in prose can drift from the configuration that ships without anything failing.
