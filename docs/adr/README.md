# Architecture Decision Records

ADRs registram decisões que alteram contratos, fronteiras ou operação do Apollo Video v2.

Estados usados:

- **Proposed:** ainda pode mudar antes da implementação dependente.
- **Accepted:** decisão vigente.
- **Superseded:** substituída por outro ADR, mantendo histórico.

Índice completo. Até a Wave 20 este índice listava 63 dos 151 ADRs existentes
e chamava a si mesmo de "índice inicial": faltavam ADR-003, 004, 005, 007, 008,
009, 011, 012 e toda a faixa de ADR-072 a ADR-151, inclusive os ADR-131 e ADR-135
que a spec 05 cita. Um índice parcial que não diz ser parcial é pior do que
nenhum: ele faz uma decisão existente parecer inexistente. O título de cada
entrada abaixo é o cabeçalho do próprio arquivo, exceto nas entradas que já
tinham título curado aqui, que foram preservadas.
